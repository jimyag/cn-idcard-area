# cn-idcard-area

用中国大陆身份证号码的前 6 位离线查行政区划。数据编译进 Go 二进制，不依赖第三方 Go 模块，查询时不需要联网或单独携带 CSV。

需要 Go 1.22 或更高版本。在仓库根目录运行：

```console
$ go run . 440305
广东省 / 深圳市 / 南山区
$ go run . 110103
北京市 / 崇文区
$ go run . 999999
未知
```

只接受一个参数，必须是 6 位 ASCII 数字。未收录的 6 位码输出 `未知`；参数格式错误时输出用法，编译后的 CLI 退出码为 `2`。直辖市、省直管县和不设区的市按实际层级输出，省略不存在的层级。

同一码有多条记录时，取启用年份最新的一条。历史码保留该记录中的地名，例如 `110103` 输出原崇文区，不追踪为东城区。查询结果是地址码对应的区划，不能确定持证人的现住址，也不能用来判断身份证是否有效。

内置数据为 [yescallop/areacodes 的 1981–2025 年汇总 CSV](https://github.com/yescallop/areacodes/blob/e2c2b2e1fb4ce1fb76e879aa0b80e229adaf950c/result.csv)，按 [CC0 1.0](data/LICENSE) 提供。更新时从固定的上游提交替换 `data/result.csv`，同步更新本链接并运行 `go test ./...`。
